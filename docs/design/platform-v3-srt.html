5. Un port, deux adaptateurs, repli

Un seul port SandboxRunner, deux adaptateurs derrière la même signature fermée et la même suite Gherkin : srt par défaut, OCI/Docker (lignée de docker-runner.ts, Podman ensuite par les mêmes flags) seulement là où srt n'est pas supporté. Le choix est une configuration explicite, jamais une bascule automatique ; un canari au démarrage, fermé à l'échec, refuse de démarrer (ISOLATION_UNAVAILABLE). Critère « srt non supporté » : système ou architecture hors du support (macOS avec sandbox-exec, Linux x64 ou arm64 avec bwrap, socat, ripgrep et espaces de noms utilisateur) ; kernel.apparmor_restrict_unprivileged_userns = 1 sans profil AppArmor ; conteneur sans espaces de noms utilisateur ; appelant root sans CAP_SETFCAP ; échec d'un test obligatoire du banc à la montée de version. Paradoxe : là où srt échoue faute d'espaces de noms utilisateur, Docker exige un démon root ou du rootless (qui en exige aussi) ; la niche réelle est un hôte Linux avec démon Docker rootful et sysctl non modifiable (rootless sans sysctl : lu, non testé, O-31 en brique D). L'absence de Docker sur macos-latest est déduite, non vérifiée. Les autres candidats ci-dessous s'ouvrent si T-41 échoue pour une raison structurelle sur un OS ciblé (non déclenché : T-41 passe sur les deux OS), si un test d'évasion réussit sans correction possible dans srt, ou si une montée de version casse une propriété prouvée. Tout est à évaluer au déclenchement, sans décision, et le test de pérennité (mesure du 30 octobre 2026) est alors rejoué : détail au §4.11 du document source.

6. Outil de code isolé, stage 0 simplifié (brique 1a.0)

Ce système simplifié est le stage 0 : un port SandboxRunner avec l'adaptateur srt, le profil builder (copie par clone --no-hardlinks, denyWrite, descripteurs créés par l'adaptateur) et une seule commande qui lance la version précédente épinglée de Claude Code dedans. Le reste de 1a et 1b se construit à l'intérieur de l'outil. Le premier stage 0 est construit hors sandbox, dans le Claude Code non sandboxé du propriétaire.
