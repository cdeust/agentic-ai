ai-architect.tools, architecture plateforme v3 sous srt

Diagrammes tirés de docs/design/platform-v3-srt.md (révision du 30 octobre 2026, base 1746cc8), qui amende la vision v3 du 29 octobre 2026. Plus de platformd, plus de protocole JSON lines : MCP stdio et Agent SDK officiels, broker seul détenteur de la clé Anthropic, profils au format Claude Code. Multi-utilisateur bloqué tant que la suite d’évasion ne passe pas sur Linux et macOS. architect-os est un nom provisoire. Les expériences T-xx et E-xx sont consignées au journal du document source ; rien n’a été prouvé sur Linux à ce stade (brique 1b.0).
